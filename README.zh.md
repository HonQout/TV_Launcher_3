# TV Launcher 3

[English](./README.md) | **简体中文**

## 简介
TV Launcher 3是一个为Android电视设计的启动器应用，使用Kotlin和Jetpack Compose开发。

## 核心功能
1. 只需简单地将喜欢的应用固定在主页面上，就可以直接访问它们。
2. 显示设备上所有可启动的应用并提供管理它们的入口。
3. **实验性** 显示来自输入源的画面。
4. 快速访问常用的系统设置项。

## 快速上手
### 系统要求
推荐系统版本：Android 11 (API 30) 及以上

最低系统版本：Android 7.0 (API 24) 及以上

支持的CPU架构：armeabi-v7a, arm64-v8a, x86, x86_64

### 安装指南
1. 在页面右侧Releases中点击最新版本，打开版本详情页面；
2. 下滑，找到Assets中的TV_Launcher_3_`<版本名称>`_all.apk，点击下载；
3. 在设备上启用“安装未知来源的应用”功能；
4. 将安装包导入设备，点击安装。
